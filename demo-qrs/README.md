Mỗi mã tương ứng 1 box trong DB.

| Box   | Giá trị quét (QR Code) | Ghi chú |
|-------|------------------------|---------|
| BOX-A01 | `QR-BOX-A01` hoặc `BOX-A01` | Demo cũ + fallback theo box.Code |
| BOX-A02 | `BOX-A02` | |
| BOX-A03 | `BOX-A03-FF251FA4` | (trùng code đã resolve bằng suffix) |
| BOX-A04 | `BOX-A04` | |
| BOX-A05 | `BOX-A05` | |
| BOX-A06 | `BOX-A06` | |
| BOX-A07 | `BOX-A07` | |
| BOX-A08 | `BOX-A08` | |
| BOX-B01 | `BOX-B01` | |
| BOX-B02 | `BOX-B02` | |

Cũng chấp nhận format sticker: `CRABSENSE:BOX:BOX-A02`

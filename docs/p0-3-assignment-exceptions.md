# P0.3 — assignment exceptions

Manager in assigned area may cancel or reassign only before recorded outcomes, with reason. New Staff must be active, assigned to same Manager and area; assignment returns to Assigned. Manager may skip a line only after recorded Dead/Missing or changed location (moved with pending harvest/molt evidence blocked). Skipped line preserves pending evidence, does not enter voucher or totals; remaining lines can proceed, including all-skipped review. Staff may record Missing on reserved assignment without pending harvest/molt evidence; reservation remains until Manager resolves. Existing voucher reservation guard retained. Audit JSON append events for submissions, returns, confirmations, cancellation, reassignment and skipped line (actor/time/reason). Legacy tasks have no retroactive audit. Not a general event-sourcing system. Remaining risks: transfer and lot closure guards, voucher exception handling, physical harvest pending mortality reconciliation, historical correction and UI reporting. No change to 45-day policy or direct voucher workflow.

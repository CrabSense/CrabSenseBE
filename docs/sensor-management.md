# Sensor management API
Platform/System Administrator: GET /api/sensors (legacy DTO, latest measurement), GET /api/sensors/{id}, existing POST/PUT/DELETE; GET /inventory and /{id}/inventory (enriched), /summary, /types, /discovered; POST /register-from-port; PUT /{id}/binding; POST /{id}/enable, /disable; GET /{id}/health, /measurements, /statistics, /chart, /events, /configuration, /calibrations; PUT /{id}/configuration; POST /{id}/calibrations; POST /{id}/test returns 501 until remote sampling is integrated.
History date filters ISO 8601 offset, from inclusive to exclusive; page 1+, pageSize 1–2000. Statistics grouped by unit; chart max 31 days, 2000 buckets, 100000 raw rows. Location is current metadata.
Configuration body samplingIntervalSeconds, disconnectTimeoutSeconds, expectedVersion; applied version reported by device. Manual calibration body performedAt, referenceValue, observedValue, unit, method, result (Passed/Failed), note; no automatic hardware adjustment.
Edge V2 device-specific credential and X-Edge-Protocol: 2: GET /api/iot/sensors/{id}/configuration?deviceCode=..., PUT /configuration/ack {deviceCode,version}, POST /errors {deviceCode,errorCode:ReadFailed|CommunicationFailed|InvalidData}. Ownership verified. Ingest requires active registered sensor, current bound port and matching unit; samples older than 30 seconds saved as Backfill, no automation. Legacy unbound sensors remain supported. Bus address/register is metadata, not a driver. Firmware/Kiosk must implement polling/ack/errors; no remote test/calibration execution yet. Existing thresholds retained, System Admin cannot change them through CRUD; new farm threshold config remains farm-owned.
Migration 20261113190000_SensorManagement adds nullable metadata, version fields and SensorCalibrations; existing readings preserved.

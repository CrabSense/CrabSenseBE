# Sensor management API
Platform/System Administrator: GET /api/sensors (legacy DTO, latest measurement), GET /api/sensors/{id}, existing POST/PUT/DELETE; GET /inventory and /{id}/inventory (enriched), /summary, /types, /discovered; POST /register-from-port; PUT /{id}/binding; POST /{id}/enable, /disable; GET /{id}/health, /measurements, /statistics, /chart, /events, /configuration, /calibrations; PUT /{id}/configuration; POST /{id}/calibrations; POST /{id}/test queues a diagnostic request (202), GET /{id}/tests and /{id}/tests/{testId} expose status.
History date filters ISO 8601 offset, from inclusive to exclusive; page 1+, pageSize 1–2000. Statistics grouped by unit; chart max 31 days, 2000 buckets, 100000 raw rows. Location is current metadata.
Configuration body samplingIntervalSeconds, disconnectTimeoutSeconds, expectedVersion; applied version reported by device. Manual calibration body performedAt, referenceValue, observedValue, unit, method, result (Passed/Failed), note; no automatic hardware adjustment.
Edge V2 device-specific credential and X-Edge-Protocol: 2: GET /api/iot/sensors/{id}/configuration?deviceCode=..., PUT /configuration/ack {deviceCode,version}, POST /errors {deviceCode,errorCode:ReadFailed|CommunicationFailed|InvalidData}. Ownership verified. Ingest requires active registered sensor, current bound port and matching unit; samples older than 30 seconds saved as Backfill, no automation. Legacy unbound sensors remain supported. Bus address/register is metadata, not a driver. Firmware/Kiosk must implement polling/ack/errors; remote test execution requires implementing the diagnostic poll/result contract; no remote calibration adjustment. Existing thresholds retained, System Admin cannot change them through CRUD; new farm threshold config remains farm-owned.
Migration 20261113190000_SensorManagement adds nullable metadata, version fields and SensorCalibrations; existing readings preserved.

Diagnostic testing: POST /api/sensors/{id}/test creates a Pending request with a 2-minute deadline; requires approved device with device-specific credential. GET /api/iot/sensor-tests/pending?deviceCode=... returns current requests to Edge V2; PUT /api/iot/sensor-tests/{testId}/result {deviceCode,success,measuredAt,value,unit,message} records authenticated results. Successful results require fresh sample and matching unit; never enter WaterMeasurements or automation. Expired/cancelled requests cannot be completed. Firmware must actually read the sensor before reporting success.
Farm-only legacy overrides: GET /api/sensors/{id}/thresholds (assigned farm read), PUT /api/sensors/{id}/thresholds (assigned Farm Administrator). Both null clears the legacy override so normal AlertThreshold applies. System Admin cannot change these.
Migrations: 20261113191000_SensorDiagnosticRuns stores diagnostic lifecycle; 20261113192000_SensorCodeUniqueness enforces existing global exact SensorCode semantics. If legacy duplicate codes exist, migration fails with a reconciliation message instead of deleting data.

# FE/App-only VPS mode

The owner confirmed that the current VPS is not connected to physical pumps or ESP32 actuators. Deploy after successful main CI without waiting for live hardware commissioning. This workflow always sets EdgeSync:ControlDisabled=true and RasAutomation:FirmwareInterlockVerified=false in both staged configuration and the systemd service. It disables legacy shared credentials. Manual and automated queue writes, poll and ACK are blocked at the service; RAS manual operations return 503 and automatic control does not enqueue. Hardware water-analysis start and device restart remain 501. Telemetry/read APIs and ordinary FE/App business operations remain available with their normal authorization.

The health endpoint /health/edge-control must report hardwareControlDisabled=true before DEPLOY_OK. Backup, schema migration, exact main CI, and schema-compatible rollback remain mandatory; rollback additionally requires an earlier package with the hardware-disabled marker. Do not connect physical hardware to this VPS or enable live operation merely by changing a variable. Live cutover requires a separate reviewed release and verified interlocks, firmware and Kiosk commissioning. This is a software lock, not an electrical emergency stop.

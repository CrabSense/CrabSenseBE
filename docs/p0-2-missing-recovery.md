# P0.2 recovery of missing crab
Manager-only correction POST /api/crabs/{id}/recover {boxId,reason}. Same last assigned area and open linked lot, actual empty active box, no open allocation, no terminal harvest/mortality or reservation conflict. Preserve ID, code, QR, registered count, old allocation and historical measures; record new allocation, actor/time/reason and box history. Set Alive/Problem and unknown shell stage until Staff checks again. Recovery and harvest share advisory lock; concurrency tokens protect crab/box/lot. No new migration. Closed lots require a separate audited correction policy; not reopened automatically. Manual end-to-end acceptance deferred to consolidated test.

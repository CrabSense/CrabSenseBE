# P2.4.5 WaterBench platform monitoring
GET /api/system/water-bench/stations?page=1&pageSize=25 (1–50). AppRoles.Platform only. Returns paged technical station/kiosk identifiers, configured hardware pair and configuration revision, recorded kiosk status/time, technical receipt freshness, camera/clock counts, retryable/contract-blocked/expired/active AI attempt counts created in last 24h. Historical counts are not current incidents; recent receipt is not live hardware verification. No farm area IDs/names, raw payloads, reagent protocols, sample source, schedule times, images, concentrations, review or credential data. No mutation/commands. Uses existing schema and station/time index; no migration. Unit/in-memory tests cover authorization metadata, redaction, window, pagination; PostgreSQL/production permission smoke still required.

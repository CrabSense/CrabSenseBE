# P2.3.4 — supervised ammonia reference
GET/POST .../results/NH3/ammonia-reference. FarmManage POST with requestId, method (printed_table or equilibrium), salinityMeasurementId, sameSampleSourceConfirmed, measurandConfirmed, reason. Uses stored NH3 sample/image-link receipts and AI provenance, never client-provided pH/temp/concentration. Salinity must be a same-area realtime edge measurement with ppt and a passed calibration within 30 days before reading. Conservative ten-second alignment including anchor RTT; no proof of clock drift, physical source or pH/temperature calibration. Operator attests source and measurand. Printed lookup only for NH4 and exact chart/pH table cells, no interpolation; equilibrium separately for NH4 or TAN-N in supported domain; free NH3 is not converted again. Append one reference with digest to existing assessment, no change to original optical result or production values; exact retry returns stored reference. Different method requires a new workflow/revision not implemented here. No automatic treatment or chemical validation. Actual sensor source mapping and calibration acceptance remain commissioning tasks.

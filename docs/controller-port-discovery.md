# Controller port discovery (Edge V2)
Signed heartbeat capability manifest is forwarded by Kiosk to POST /api/iot/controllers/capabilities using the per-device credential. GET /api/iot/controllers/{id}/ports is role/area scoped. PUT /api/iot/controllers/{id}/ports/{portId}/sensor binds a registered direct input (System Admin). Existing RAS binding validates discovered outputs. Manifest version is monotonic, changed layout requires new version, output state is excluded from layout fingerprint. Missing ports remain stored as Disabled, new/changed ports Pending. Initial discovery links uniquely matching existing RAS channel metadata and exact same-device sensor codes; no new sensor or load is fabricated. Port IsPresent means supported by firmware, not physically attached. Only Verified ports with exact binding can be used by the new command guard; no commissioning endpoint or live control enablement in this change. Legacy control remains globally locked. Real commissioning, command layout-version binding, interlocks and expansion sequence migration required before ON. No FE/App, sales or quarantine changes. Migration 20261113120000_DiscoverControllerPorts adds ControllerPorts, Devices capability metadata and nullable sensor/actuator port FKs; preserves old mappings. Actual smart-module drivers and physical Kiosk integration not supplied.
